# MovieHub 

A movie booking platform that allows users to browse movies, view details, and book movies.

---

## Features

- Browse movies 
- Search movies
- View movie details
- User authentication (Firebase)
- Admin dashboard 
- Loading and error handling
- Protected routes

---

## Tech Stack

- React 
- Tailwind CSS
- Firebase Authentication
- React Router

---

## Installation

```bash
npm install
```

## Running the app
- npm run dev
